소개

AI 스튜디오 업로더는 채널 운영자 한 사람이 자기 컴퓨터에서 직접 만든 짧은 영상(쇼츠)을 자기 YouTube 채널에 올리는 개인용 데스크톱 도구입니다. 운영자 외의 사용자는 없으며, 앱을 배포하거나 판매하지 않습니다.

  • YouTube Data API v3로 운영자 본인 채널에 영상 업로드 (제목·설명·태그·공개 범위·예약 공개)
  • 업로드한 영상의 공개 통계(조회수·좋아요·댓글 수) 확인

AI Studio Uploader is a personal desktop tool used by a single channel owner to upload short videos they made to their own YouTube channel through the YouTube Data API v3, and to view public statistics of those videos. It has no other users and is not distributed or sold.

개인정보처리방침

시행일: 2026년 11월 3일 · Effective: November 3, 2026

1. 수집·이용하는 정보

  • Google OAuth 토큰: 운영자가 Google 계정으로 로그인해 허용하면 받는 접근 토큰과 갱신 토큰. 업로드(youtube.upload)와 채널 확인(youtube.readonly) 권한만 요청합니다.
  • 채널 정보: 로그인한 계정의 채널 ID와 채널 이름 (어느 채널에 올릴지 고르는 데만 사용)
  • 영상 정보: 운영자가 올리는 영상 파일과 제목·설명·태그, 업로드 후 받는 영상 ID와 공개 통계

The app uses Google OAuth tokens (scopes: youtube.upload, youtube.readonly), the channel ID and title of the signed-in account, and the videos and metadata the owner chooses to upload, plus the resulting video IDs and public statistics.

2. 보관 방법

모든 정보는 운영자 본인의 컴퓨터에만 저장됩니다. OAuth 토큰과 클라이언트 정보는 Windows 자격 증명 관리자에 암호화되어 보관되며, 별도의 서버나 클라우드로 전송·저장하지 않습니다.

All data stays on the owner's own computer. OAuth tokens are stored encrypted in Windows Credential Manager. Nothing is sent to or stored on any server operated by the developer.

3. 제3자 제공

수집한 정보를 판매하거나 제3자에게 제공하지 않습니다. 정보는 Google(YouTube) API를 호출할 때만 Google로 전송되며, 광고·분석·AI 학습 등 다른 목적으로 쓰지 않습니다.

Data is never sold or shared with third parties. It is only sent to Google when calling the YouTube API, and is not used for advertising, analytics or AI training.

4. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함해 이를 준수합니다.

AI Studio Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube 서비스

이 앱은 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 정보 처리는 Google 개인정보처리방침을 따릅니다.

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google handles data under the Google Privacy Policy.

6. 삭제와 접근 철회

  • 앱의 [연결 해제]를 누르면 저장된 토큰을 지우고 Google에도 토큰 폐기를 요청합니다.
  • 언제든지 Google 계정 → 보안 → 서드 파티 액세스에서 이 앱의 권한을 직접 철회할 수 있습니다.
  • 영상 통계 기록 등 컴퓨터에 남은 파일은 앱 폴더의 logs 폴더를 지우면 모두 삭제됩니다.

Use "연결 해제 (Disconnect)" in the app to delete stored tokens and revoke them with Google, or revoke access at any time at Google Account → Third-party access. Local logs can be deleted by removing the app's logs folder.
